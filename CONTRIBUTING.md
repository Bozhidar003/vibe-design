# Contributing to Vibe Design

Thanks for your interest in contributing! Here's how to get started.

## Development Setup

```bash
git clone https://github.com/Bozhdiar003/vibe_design.git
cd vibe_design
npm install
npm run build
```

## Making Changes

1. Fork the repo and create a branch from `main`
2. Make your changes
3. Run `npm run build` to verify the build passes
4. Commit your changes with a clear message
5. Open a pull request

## Code Style

- TypeScript throughout
- ESM modules (`"type": "module"`)
- Built with `tsup`

## Reporting Bugs

Open an issue at https://github.com/Bozhdiar003/vibe_design/issues with:
- Steps to reproduce
- Expected vs actual behavior
- Your environment (Node version, OS, framework)
