# Changelog

## 0.1.0

Initial release.

- CLI with `init`, `start`, `sync`, `detect`, `task`, `eject`, `design-system` commands
- Browser overlay with element selection and AI-powered code editing
- Stack detection for Next.js, Vite, Remix, SvelteKit, Nuxt
- CSS detection for Tailwind (with config parsing), CSS Modules, styled-components, Emotion
- Component detection for shadcn/ui, Radix, Mantine, Chakra, MUI
- Adapters for Next.js, Vite, Remix, SvelteKit, and generic HTTP proxy
- Design system rules enforced in every prompt
- Simple mode for minimal UI
